# 울림 — 지금 듣는 음악으로 하는 다이얼 리듬 게임

다른 앱(유튜브, 음악 앱 등)에서 노래를 틀어 두면, 폰에서 나오는 소리를 실시간으로 분석해
박자(BPM)를 잡고 그 박자에 맞춰 게임이 진행됩니다. 파일을 넣을 필요가 없어요.

## 게임 방법

- 화면 가운데 **코어**가 음악 박자에 맞춰 뜁니다.
- 바깥에서 파동이 박자에 맞춰 안쪽으로 조여 옵니다. 궤도(얇은 원)에 닿는 순간이 판정 시점입니다.
- **손가락을 화면에서 원 모양으로 돌리면** 궤도 위의 내 빛이 따라 돕니다(다이얼 조작).

| 파동 | 하는 일 |
|---|---|
| 색깔 벽 고리 | 빈틈이 있어요. 빈틈에 내 빛을 두면 통과, 아니면 충돌 |
| 빛 구슬 | 궤도에 닿을 때 그 자리에 있으면 수집 |
| 흰 고리(공명) | 곡이 고조될 때 와요. 궤도에 겹치는 순간 **아무 곳이나 탭**(다른 손가락으로 탭해도 돼요) |

- 패턴은 음악 성격을 따라갑니다. 저음이 세지면 벽이 많아지고, 하이햇이 많으면 반박자 구슬이 나오고, 에너지가 확 오르면 흰 고리가 나옵니다.
- 실수하면 **하모니** 게이지가 줄고, 0이 되면 끝. 콤보가 쌓일수록 점수 배율이 오르고 빈틈은 좁아집니다.
- 노래가 바뀌어도 게임은 이어집니다. 새 템포를 다시 잡아요.

## 설치 (PC 필요, 처음 한 번만)

1. PC에 **Android Studio**를 설치합니다(무료, developer.android.com/studio).
2. 이 폴더(`ullim`)를 Android Studio에서 **Open**으로 엽니다. 처음엔 필요한 도구를 내려받느라 몇 분 걸려요.
   - 버전을 올리라는 안내(AGP Upgrade Assistant 등)가 나오면 그대로 따라도 괜찮아요.
3. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 USB로 연결합니다.
   - 개발자 옵션: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭
4. 위쪽의 ▶ **Run** 버튼을 누르면 폰에 설치되고 바로 실행됩니다.

**APK 파일로 뽑고 싶다면:** 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
완료 알림의 *locate*를 누르면 `app/build/outputs/apk/debug/app-debug.apk`가 나옵니다.
이 파일을 폰으로 옮겨 열면 설치돼요("출처를 알 수 없는 앱" 허용 필요).

## 처음 실행할 때

1. **시작하기** → 오디오 권한 허용 → 화면 공유 창에서 **전체 화면**으로 시작.
   (화면 녹화는 하지 않아요. 안드로이드에서 다른 앱 소리를 받으려면 이 허용이 꼭 필요해요.)
2. 음악 앱으로 가서 노래를 틀고 다시 울림으로 돌아오세요.
3. 몇 초 안에 오른쪽 위에 BPM이 뜨면 게임이 시작됩니다.

## 싱크 맞추기

화면 아래 **− / +** 버튼으로 조절합니다. 코어가 **귀에 들리는 박자**에 맞춰 뛰도록 맞추면 돼요.

- 폰 스피커/유선 이어폰: 0 ~ +60ms 근처
- **블루투스 이어폰: +150 ~ +250ms** 정도 필요한 경우가 많아요(블루투스 지연 때문)
- 값은 저장돼서 다음에도 유지됩니다.

## 알아 둘 점

- Android 10 이상에서만 동작합니다. 아이폰은 운영체제가 다른 앱 소리를 못 가져오게 막아서 불가능해요.
- 일부 앱은 소리 캡처를 막아 둡니다. "소리 없음"이 계속 뜨면 다른 앱으로 노래를 틀어 보세요.
- 소리는 메모리에서 박자 분석에만 쓰고 어디에도 저장하거나 보내지 않습니다.
- 박자 인식은 드럼이 분명한 곡(팝, 힙합, EDM, 록)에서 가장 잘 됩니다. 박자가 흐린 곡(발라드 인트로, 클래식)은 늦게 잡히거나 못 잡을 수 있어요.
- 아주 빠른 곡은 두 박에 하나, 느린 곡은 두 배 박자로 잡힐 수 있어요. 둘 다 정상 동작입니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `CaptureService.kt` | 화면 공유 허용으로 다른 앱 소리를 받아오는 포그라운드 서비스 (AudioPlaybackCapture) |
| `Audio.kt` | FFT → 스펙트럴 플럭스 → 자기상관으로 템포, 저음 가중 콤 필터로 박자 위상, 예측 박자 시계 보정 |
| `GameView.kt` | 게임 로직, 다이얼 입력, 판정, 그리기 (SurfaceView 60fps) |
| `MainActivity.kt` | 권한, 화면 공유 요청, 전체 화면 |

외부 라이브러리 없이 안드로이드 기본 API만 씁니다. 판정 범위, 파동 속도(`TRAVEL`), 패턴 규칙은
`GameView.kt` 위쪽 상수와 `pattern()` 함수에서 바꿀 수 있어요.
